# PC Agent

উইন্ডোজ পিসির জন্য বাংলা এজেন্ট ড্যাশবোর্ড — নিজের **লগইন করা ফ্রি ওয়েব AI** (Gemini / ChatGPT / DeepSeek / Duck.ai) দিয়ে কাজ চালায়। কোনো API কী কেনা লাগে না: একবার ব্রাউজারে লগইন করলেই এজেন্ট হিডেন ব্রাউজারে নিজে কাজ করে। সাথে পিসি কন্ট্রোল (মাউস-কিবোর্ড, স্ক্রিন, ফাইল), ফোন কন্ট্রোল, ডাবিনচি রিসলভ ও যেকোনো অ্যাপ চালানোর টুল, আর টেরাবক্স ডেটা-লেন।

## এক কমান্ডে সেটআপ

```bat
git clone https://github.com/nlnazmulchowdhury-blip/Ai.git pc-agent && cd pc-agent && setup.cmd
```

(`nlnazmulchowdhury-blip/Ai` — এই রেপোর নিজের ঠিকানা; প্রাইভেট হলে আগে `gh auth login` বা Git Credential Manager দিয়ে লগইন লাগবে।)

`setup.cmd` নিজে থেকে:

1. Node.js ২০+ আছে কি না দেখে, না থাকলে ইনস্টল করে (winget, না পারলে পোর্টেবল কপি),
2. `npm install` (শুধু ৩টি ছোট প্যাকেজ — Playwright ব্রাউজার ডাউনলোড লাগে না, সিস্টেমের Chrome/Edge ব্যবহার হয়),
3. `data/config.json` ডিফল্ট বট-দল সহ বানায়,
4. ডেস্কটপ/স্টার্ট-মেনু শর্টকাট + লগইনে অটোস্টার্ট বসায়,
5. সার্ভার চালু করে ব্রাউজারে **সংযোগ পাতা** (`/setup`) খোলে।

## এরপর শুধু লগইন

`/setup` পাতায় প্রতিটি সাইটের পাশে **লগইন করো** বাটন। একবার ব্রাউজারে লগইন করলে:

- কার্ড সবুজ হয়ে "সংযুক্ত" দেখায়,
- সেশন `profiles/` ফোল্ডারে থাকে — পরের বার আর লগইন লাগে না,
- এজেন্ট নিজেই হিডেন ব্রাউজারে ওই সাইট ব্যবহার করে।

পাসওয়ার্ড কোথাও লেখা, পাঠানো বা commit হয় না — লগইন সবসময় তুমি নিজে করো।

**টেরাবক্স:** টেরাবক্স কার্ডে লগইন করলেই ডেটা-লেন কানেক্ট — আলাদা AList বা টোকেন লাগে না। (`ALIST_URL`/`ALIST_TOKEN` থাকলে সেটাই আগে ব্যবহার হয় — `.env` ঐচ্ছিক।)

## চালানো

| কী | কীভাবে |
| --- | --- |
| ড্যাশবোর্ড | ডেস্কটপের **PC Agent** আইকন, বা `http://127.0.0.1:4780` |
| সংযোগ পাতা | `http://127.0.0.1:4780/setup` |
| কাজ দেওয়া | ড্যাশবোর্ডের চ্যাট, বা `npm run task -- "কাজ"` |
| হালকা চ্যাট | কর্নারের হাট (ডান-নিচ), `http://127.0.0.1:4780/widget` |
| ফোন | একই WiFi-তে ড্যাশবোর্ডের শেয়ার লিংক |

## ডেটা কোথায় থাকে

`data/` (কনফিগ, টাস্ক, সংযোগ-স্ট্যাটাস), `profiles/` (ব্রাউজার সেশন), `workspace/` (ফাইল)। এই তিনটাই git-এ যায় না।

## সমস্যা হলে

- **সার্ভার ওঠে না:** `data/server.log` দেখো; পোর্ট ব্যস্ত থাকলে `set PORT=4781` দিয়ে চালাও।
- **লগইন রাখে না:** একই সাইট অন্য Chrome উইন্ডোতে খোলা থাকলে প্রোফাইল লক হতে পারে — ওই উইন্ডো বন্ধ করে আবার চেষ্টা করো।
- **Chrome নেই:** Microsoft Edge দিয়েও চলে (`accounts[0].browser = "edge"`)।
